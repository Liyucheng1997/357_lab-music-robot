# 音隅 · 聚合音乐

一处搜遍各大音乐平台，附带网易云排行榜、网易云推荐歌单，以及根据你的听歌习惯生成的个性化推荐。

版本 **v1.0.0** · [在线页面](https://liyucheng1997.github.io/357_lab-music-robot/) · [版本记录](CHANGELOG.md)

## GitHub Pages

推送到 `main` 后，GitHub Actions 自动测试并将 `public/` 部署到 Pages。

`server/`、`public/` 或 `package.json` 有改动并推送到 `main` 时，`Deploy Backend` 工作流会测试后通过受限 SSH 钥匙登录服务器，执行 `/usr/local/bin/deploy-music`：拉取 `main`、重启 `app-music` 服务并做健康检查。也可以在 Actions 页面手动运行。

Pages 仅托管前端，无法运行本项目的 Node.js API。未连接后端时可以访问页面、浏览本地收藏并使用官方平台入口；聚合搜索、榜单、推荐、歌词和音频解析需要单独部署后端。

将此仓库部署到支持 Node.js 的服务器，启动命令为 `npm start`，配置环境变量：

```text
HOST=0.0.0.0
PORT=3570
CORS_ORIGINS=https://liyucheng1997.github.io
```

为后端配置 HTTPS。在线页面默认连接已部署的后端 `https://music.liyucheng.me`（见 [public/js/backend.js](public/js/backend.js) 的 `DEFAULT_BACKEND`），也可以在页面上方「连接音乐服务」改填其他后端根地址，清空则恢复默认。地址只保存在当前浏览器；B站音轨会自动使用该后端的转发地址。后端接口须允许上述 Pages 来源的跨域请求。

## 运行

需要 Node.js 18.17 及以上版本，项目没有任何第三方依赖。

```bash
npm start
```

启动后打开 http://127.0.0.1:3570 。可以用环境变量 `PORT` 和 `HOST` 修改端口和监听地址。

## 功能

| 功能 | 说明 |
| --- | --- |
| 聚合搜索 | 同时搜索网易云、酷狗、酷我和B站，同名同歌手同版本的结果合并，点来源标签跳到原平台。抖音、汽水音乐另设「官方入口」标签 |
| 免费播放 | 汇总网易云、酷狗公开的免费音频与B站视频音轨。原平台为 VIP 的歌曲可以匹配其他平台公开免费版本；没有免费版本则无法站内播放。不绕过 VIP 校验。视频可能与录音室录音不同，单独标注 |
| 资源与音质 | 歌名旁显示默认资源的低／中／高音质，点击展开可用资源并选择播放。默认显示和播放音质最高的资源，同等级优先码率较高的资源；等级与码率相同才优先歌曲音频及原平台。缺少信息显示「音质未知」，不显示编码参数。接口失败与没有资源分别展示，支持重新查询。公开地址可能受地区、权限、有效期影响 |
| 抖音／汽水 | 未配置授权曲库接口，当前提供官方入口，不提供站内曲库或播放。抖音跳转关键词搜索，汽水打开官网下载／客户端入口。取得授权接口后才能进一步接入 |
| 排行榜 | 网易云官方的飙升、新歌、热歌、原创、说唱、ACG、欧美、韩语、日语、电音榜 |
| 网易云推荐 | 首页展示推荐歌单和新歌速递 |
| 为你推荐 | 根据本地的听歌记录、收藏和「不感兴趣」生成音乐画像，再用四路召回给出推荐，每首歌附带推荐理由 |
| 桌面歌词 | 双行卡拉 OK 歌词，浮在所有窗口之上，可调字号、5 种配色、切换显示翻译，小窗里也能切歌和暂停。Chrome / Edge 用置顶小窗（Document Picture-in-Picture），Safari 用视频画中画，其他浏览器在页面内显示可拖动的歌词条 |
| 播放器 | 播放队列、三种播放模式、滚动歌词（含翻译，点歌词可跳转）、锁屏和耳机按键控制、深色模式、移动端适配 |

快捷键：`/` 搜索，`空格` 播放/暂停，`←` `→` 快退/快进 5 秒，`Shift + ←/→` 上一首/下一首，`L` 打开歌词页，`D` 桌面歌词，`Esc` 关闭。

## 推荐算法

[server/recommend.js](server/recommend.js)

1. **画像**：每首听过的歌按 `log2(1 + 播放次数) − 0.6·log2(1 + 跳过次数)` 计分，再乘以时间衰减（约三周半衰）。收藏的歌 +3 分，不感兴趣的歌 −2 分。分数累加到对应的歌手上。
   - 「播放」指听满 30 秒或歌曲时长的一半。
   - 「跳过」指不到 10 秒就手动切走。
2. **召回**：候选歌曲来自四个渠道。
   - 种子歌曲的网易云相似歌曲
   - 常听歌手的热门作品
   - 相似歌手的热门作品
   - 热歌榜、飙升榜、新歌榜中与画像重合的歌
3. **排序**：被多个渠道召回的歌会加分，听过的和不感兴趣的会被过滤。同一位歌手最多出现 3 首，保证推荐有多样性。
4. **冷启动**：还没有听歌记录时，推荐热门榜单歌曲。

所有听歌数据只存在浏览器的 localStorage 里，服务端不保存任何用户数据。

## 说明

- 音质等级按接口码率粗略分类：低于 128 kbps 为低，128–255 kbps 为中，256 kbps 及以上为高；未提供可靠数据时为未知。等级用于默认资源选择，不代表不同编码、录音版本的绝对听感。

- 本项目调用的是各平台网页端的公开接口，这些接口随时可能变化。某个平台失败时，搜索页对应的标签会显示「失败」，其余平台照常可用。
- 版权归各平台和版权方所有。本项目只做检索和导流，不提供下载，也不绕过付费限制。
